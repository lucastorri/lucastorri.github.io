Privacy policy

Scope

This policy covers a private application used by a single person, its operator. It is not distributed and has no other users. The only Google account it accesses is the operator's own.

Google user data accessed

The application requests one Google OAuth scope, https://www.googleapis.com/auth/gmail.readonly, and reads only messages the operator has selected. It never sends, modifies or deletes email, and it does not access any other Google service.

How the data is used

Selected messages are copied to storage controlled by the operator so the operator can read and organise them. The data is not used for advertising or profiling and is not used to train AI models.

Storage

Messages and access credentials are stored only on devices and storage the operator controls. The application has no server or database of its own.

Sharing

Google user data is not sold or shared. When the operator asks for it, message content may be processed by a service acting on the operator's behalf, solely to provide that requested feature.

Limited Use

The application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Copied messages remain until the operator deletes them. Access can be revoked at any time at myaccount.google.com/permissions.
